# منصة مراجعة التصاميم الفراغية وتنسيق نماذج الـ BIM عبر الويب
## Open-Source WebXR BIM Design Review & Coordination Platform

تم تطوير هذا النموذج الأولي المتكامل (**Starter Template**) لخدمة الجانب العملي في رسالة الماجستير:
> **"توظيف تقنيات الواقع المعزز والافتراضي (AR/VR) كمنصات تفاعلية لمراجعة التصميم المعماري والإشراف الوقعي"**

تعتمد المنصة على معيار **WebXR** المفتوح ومكتبة **Three.js** للعمل مباشرة عبر أي متصفح إنترنت على الحواسيب أو داخل نظارات الواقع الافتراضي (مثل Meta Quest 3) **دون الحاجة لتثبيت محركات ألعاب ثقيلة أو بطاقات رسوميات باهظة**.

---

### 1. مميزات المنصة الوظيفية:
1. **دخول فوري للواقع الافتراضي (One-Click VR):** تفعيل تلقائي للنظارة عبر زر `ENTER VR` المتوافق مع معيار WebXR العالمي.
2. **استنطاق البيانات الوصفية (BIM Semantic Metadata):**
   * عند توجيه الليزر في الـ VR أو النقر بالماوس على الحاسوب نحو أي عنصر (مجرى هواء، ماسورة أكسجين، صمام، باب)، تظهر بطاقة بيانات متكاملة تقرأ: المعرف الفريد `Element ID`، النظام، الأبعاد، وخلوص الصيانة المطلوب.
3. **لوحة فراغية عائمة ثلاثية الأبعاد (3D Floating Billboard):** تظهر اللوحة أمام نظر المهندس مباشرة داخل النظارة وتدور تلقائياً لتواجه رأسه أينما تحرك.
4. **نظام الانتقال اللحظي (VR Teleportation):** يتيح التنقل المريح عبر اليد اليسرى لمنع أي دوار حركة (Zero Cybersickness).
5. **توثيق التعارضات وتصدير تقرير إحصائي (Issue Flagging & CSV Export):**
   * إمكانية تسجيل أي مشكلة تشغيلية يراها المهندس، فيضع النظام علامة كروية حمراء في مكان الخطأ، مع إمكانية تحميل تقرير إكسل/CSV كامل جاهز للتحليل الإحصائي في الرسالة.

---

### 2. طريقة التشغيل الفورية (خلال 30 ثانية):

المشروع مصمم ليعمل بتقنية **ES Modules** عبر رابط استيراد مباشر، لذا لا يتطلب بالضرورة أي تنزيل لحزم معقدة:

#### الطريقة الأولى (الأسرع عبر سطر الأوامر):
افتح موجه الأوامر (Terminal) داخل مجلد المشروع ونفذ:
```bash
# باستخدام بايثون المدمج في جهازك:
python3 -m http.server 8000
```
أو إذا كان لديك Node.js:
```bash
npx serve .
```

ثم افتح المتصفح على جهازك:
👉 `http://localhost:8000`

---

### 3. كيف تفتح المنصة داخل نظارة الواقع الافتراضي (Meta Quest 3)؟

1. تأكد أن نظارة الـ Quest وجهاز الكمبيوتر متصلان على **نفس شبكة الواي فاي (Wi-Fi)**.
2. اعرف عنوان الـ IP الداخلي لجهاز الكمبيوتر (مثلاً: `192.168.1.50`).
3. البس النظارة وافتح **متصفح كويست المدمج (Meta Quest Browser)**.
4. اكتب في شريط العنوان: `http://192.168.1.50:8000`.
5. ستفتح لك المنصة؛ اضغط على زر **`ENTER VR`** في أسفل الشاشة؛ ستجد نفسك فوراً داخل المستشفى بمقياس $1:1$!

---

### 4. كيف تستبدل النموذج التجريبي بنموذج Revit الحقيقي عبر Speckle؟

المنصة مجهزة للربط المباشر مع منصة **Speckle** مفتوحة المصدر:
1. قم بتثبيت إضافة **Speckle Manager** لبرنامج Revit من الرابط: [https://speckle.systems](https://speckle.systems).
2. افتح مشروعك في Revit واضغط زر **`Send to Speckle`**.
3. ستحصل على رابط تدفق (Stream URL).
4. في كود `app.js`، استبدل مصفوفة المجسمات التجريبية بكود استيراد Speckle الرسمي:
```javascript
import { Viewer } from '@speckle/viewer';

const viewer = new Viewer(container);
await viewer.init();
await viewer.loadObject('https://app.speckle.systems/projects/YOUR_PROJECT_ID/models/YOUR_MODEL_ID');
```
وستتدفق عناصر المبنى وبياناتها كاملة وتلقائياً إلى نفس واجهة الـ WebXR!
